## 1. 자동 테스트 (pytest) — 수행

- 일시: 2026-11-03, 로컬 (Python 3.11.9)
- 명령: `.venv/Scripts/python -m pytest -q`
- 결과: **65 passed**
- 범위: FastAPI 계층(인증·역할 검사·입력 검증·쿠키·CSRF·요청 제한)과 Supabase REST 요청 모양·오류 변환.
  실제 Supabase 대신 가짜 인증 서버와 RLS 규칙을 흉내 낸 메모리 저장소를 쓴다.
- 증명하지 못하는 것: 실제 PostgreSQL 의 RLS·컬럼 권한 → 2절.

주요 항목: 비로그인 401, 데모 로그인 HttpOnly 쿠키·본문에 토큰 없음, role 위조 422, 데모 버튼 값과 무관하게 DB 역할 적용,
작업자 타인 신고 조회 404, 작업자 PATCH/DELETE/초기화 403, 생성 시 status/action/due_date/reported_by/organization_id/role 지정 422,
다른 사업장 관리자 접근 404, 관리자 조치 → 작업자 조회 반영, 조치 없는 완료 400, 다른 출처 403, 비 JSON 415, 신고 요청 제한 429.
